## 2. 关键设计转向（相对 06 文档 P0-1 的修正）

文档原方案是"按 BuildingAssembly footprint 外扩 2 格打 AABB"。读码后**不可行**，已改为**细盒列覆盖驱动**：

- `addWardGateArchitecture` 的 assembly footprint = 整坊范围（`basicSpec(ctx,'gate',w.x0,w.z0,w.x1,w.z1,...)`），按 footprint 打会遮掉整坊 → 必须以**细盒投影到的宏观列**为准。
- 宏观旧内容有三类必须保留，不能一刀切：① 地标门墩/台基/龙尾道（细层没有对应物，细 frame 无台基盒）；② 露天铺装（宫城/两市地面全是 brickPave）；③ 树木（细层无植被）。
- 宏观屋顶常比细屋顶高（如大雁塔宏观 base+44 vs 细 base+21），遮蔽上沿必须取**该列 store 实际柱顶**，不能取细盒顶。

### 遮蔽规则定稿（envelopeMask 按此实现）

覆盖图：遍历 LOD0 细盒（跳过 buildingId=0 的用户涂抹），每盒投影宏观列 `[floor(x0/Q)..floor((x1-1)/Q)]×[z 同理]`；core=盒内列，ring=盒外扩 E 列（rank≥4 的 assembly E=2，否则 E=1）。每列记 `bot=min(floor(b.y0/Q))`（最低细盒底）。

逐列规则（x,z 为覆盖列，ty=该列 store 实际最高体素，gy=fields.groundH）：

1. 门扉列保护：`ctx.doors` 的 cells 列中，y∈[d.base+1, d.base+2] 不遮（保坊门/市门动态门扉）；同列其余高度照遮。
2. 树列保护：`topC ∈ 枝叶色`（huaiGreen/huaiLight/willowGreen/pineGreen/bambooGreen/wutongGreen/apricotPink/peonyRed/grass/withered/moss）→ 整列跳过。
3. 露天铺装保护（**仅 ring 列**）：topC ∈ {brickPave, stoneWhite, stoneGrey} → 整列跳过。core 列不享受此保护（core 内的铺装顶是旧台基/室内地板，细台基已接管）。
4. core 列：遮 `y ∈ [max(bot, gy+1), ty]` 内所有建筑色 = {roof*/timber*/zhu*/plaster*/doorDark/glaze*/gold/bronze/iron/brickPave/stoneWhite/stoneGrey/rammed*/clothCream/clothHu/flag*/paperWhite}。
5. ring 列：仅当 `ty ≥ bot+4` 才处理（保护廊道/武侯铺/坊墙等低矮宏观构件）；遮 y≥bot+1 的外观色 = core 集合去掉 {brickPave/stoneWhite/stoneGrey/rammed*}。
6. 永不遮：glow（lantern/candle）、水、地形色、枝叶色。
7. 护墙：ring 跳过坊墙环线、市墙环线、城墙带、宫城/皇城/大明宫 ringWall 周界列（防止 ring 误伤墙帽）。坊门亭 core 覆盖门房（柱在石墩位 cx±2，亭 core 达 cx-3..cx+1，已含）。

效果预期：旧厅/店/门楼/塔整体消失（细层接管）；宫城门墩台基、殿前广场、市砖地面、龙尾道、飞廊、廊庑、井亭、经幢、武侯铺、全部保留；高空泄漏清零。

### 为什么移除构件级 maskPrism

原小柱体是非选择性的（连地形/树一起遮）且覆盖不满出檐/屋脊；统一 pass 后它们成为子集。已删位置：fineFrame、fineHall、fineEnclosure×4、fineWarehouse、finePavilion、fineMarketTower、finePagoda、wrapTang 的 PlatformBuilder 与 RoofBuilder 内各 1 处。`maskPrism` 函数定义保留未删。
