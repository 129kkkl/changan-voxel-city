# P1 空间与尺度：三版灰模对照（方案书）

> 依据：`11_城市规模与建筑体系重建_AI执行方案.md` §P1。
> 目的：在动手做 P3/P4 之前，用**灰模（`?grey=1`）**把"规划与尺度"定死，
> 避免继续在错误的空间骨架上堆建筑。

## 0. 测量口径（冻结，不改）

| 指标 | 口径 | 现状值 |
|---|---|---|
| 主街宽 | 朱雀大街/横街的路面格数（城体素） | ZHUQUE 10、HENGJIE 16 |
| 次街宽 | MAIN 5、GATE8 8 | — |
| 巷宽 | WARD_CROSS 2、LANE 1 | — |
| 坊内分划 | 大坊四门十字街 + 四象限；小坊一字横街 + 两带 | — |
| 宅地进深 | 院落南北向格数（含院墙） | 单进为主 |
| 建筑占地率 | 坊内建筑投影 / 坊面积 | 偏高（屋脊连片） |
| 屋脊连续度 | 沿街可见独立屋顶轮廓数 / 100 格街面 | 未测 |

**判定机位（固定，全部灰模、noon、seed `5a17c4a9`、1600×900、q=mid）**
- `axis`：中轴鸟瞰（判街—坊—院等级）
- `wardGate`：坊门街景（判街宽与门内纵深）
- `lane`：坊内巷道（判院落肌理与巷两侧围合）

## 1. 方案 0（现状对照，`验收截图/p1_grey0`）

灰模诊断（三机位 6/10）：
- **街道等级读不出**：主轴最宽、其余宽度层级单一，十字街/巷级差几乎不可辨。
- **院落纵深浅**：多为单进，门内一进即止；院与院不成嵌套，屋脊连成整片。
- **坊内方块感**：坊格未显，呈"沿街房 + 方块堆叠"。

## 2. 方案 A：现状骨架 + 尺度校正（最小改动）

- 保持 108 坊与中轴不动。
- 只做两件事：① 巷宽 `LANE` 1→2、`WARD_CROSS` 2→3，让巷可辨；
  ② 单进宅地统一加深 1 进（前院—正房—后院），进深下限抬到可容纳两进。
- 预期：街道等级与院落纵深各改善一档；改动风险最低，但"方块感"仍在。

## 3. 方案 B：增加院落纵深与道路层级（推荐）

- **道路三级**：主街（ZHUQUE 10 / HENGJIE 16）→ 十字街（2→4）→ 巷（1→2）。
  级差比约 5:2:1，灰模下必须一眼看出三级。
- **坊内两级分划**：大坊四象限 → 每象限再分 2×2 宅地组团，组团间留支巷（1 格）。
- **宅地进深**：普通宅地 2 进（前堂后寝），大宅地 3 进（穿廊）；
  进深不足的宅地宁可减少数量，不压缩进深（**宁可少、不可浅**）。
- **围合**：沿巷两侧以院墙连续围合，禁止"孤立方块"直接临巷。
- 预期：坊格、巷网、院落嵌套三者同时可读；代价是建筑总数下降（预算按 §5 兜底）。

## 4. 方案 C：扩大组团（激进）

- 坊内改为 2×2 大组团 + 组团内支巷；宅地统一 3 进；
- 沿街只留"组团门面"，内部以连续屋脊 + 院墙织成肌理。
- 预期：远景屋脊肌理最好看；但单体可辨识度下降，与 P2"每栋单拉出来够看"冲突，
  且建筑数下降最多。

## 5. 对照与取舍规则

1. 三版必须用**同一组固定机位、同一 seed、同一灰模**渲染，不得换机位找好看的角度。
2. 判定三问（每问须"是"）：
   - 主街 / 十字街 / 巷的宽度级差在灰模下能否一眼分辨？
   - 能否看出"坊 → 组团 → 院落 → 单体"四级嵌套？
   - 沿街是否形成连续围合（而非孤立方块排列）？
3. 若 B 与 C 均满足三问，取建筑数下降较少者；若都不满足，回到参数重做，**不降标准**。
4. 选定后写进 `design/尺度与预算表.md` 作为 P3/P4 的硬约束（含建筑数下限）。

## 6. 实施方式

- 用查询参数 `?plan=0|A|B|C` 切换规划参数（默认 = 选定方案），保证可复现对照。
- 每版渲染 `axis` / `wardGate` / `lane` 三机位灰模 + 一次彩模，存 `验收截图/p1_<方案>/`。
- 视觉判定用同一套问题、同一模型，评分口径不随方案调整。
